## Research

**MIT EECS PhD — Nanomaterial and Electronics Group (Prof. Jing Kong)**
- Built an AI-powered automated microscope system (Python + Arduino) for pixel-level classification of 2D semiconductor materials
- Developed a computer vision method for sub-degree rotation angle detection (0.1°–5°) in 2D material heterostructure fabrication
- Applied ML embeddings on SEM and Raman spectra to correlate MOCVD synthesis recipes with device performance
- Co-authored *Text Mining of CVD Synthesis Recipes for 2D Materials*, **Advanced Materials** (2026)

**Synopsys — ML & Circuit Design Intern (Summer 2025)**
- Developed a Circuit Foundation Model (CFM) for VLSI circuits using Recurrent Hypergraph Neural Networks (RHGN)
- Designed message-passing algorithms for circuit embeddings; built modular training infrastructure (loss functions, diagnostics, visualization)

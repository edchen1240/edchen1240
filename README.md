## Research

**MIT EECS PhD — Nanomaterial and Electronics Group (Prof. Jing Kong)**
- AI-powered automated microscope system (Python + Arduino) for pixel-level classification of 2D semiconductor materials
- Computer vision method for sub-degree rotation angle detection (0.1°–5°) in 2D material heterostructure fabrication
- ML embeddings on SEM and Raman spectra to correlate MOCVD synthesis recipes with device performance

**Synopsys — ML & Circuit Design Intern (Summer 2025)**
- Circuit Foundation Model (CFM) for VLSI circuits using Recurrent Hypergraph Neural Networks (RHGN)
- Scalable message-passing architecture, training infrastructure, and model diagnostics for large circuit datasets
